# StudEx VLE

A full-stack Virtual Learning Environment built with React, Flask, and MySQL. The app supports student, lecturer, and admin workflows, with a SQL-backed API and a local demo path for reviewing the system end to end.

This repository is packaged for local demo and code review. It is not presented as a production LMS.

## What It Does

- Students can log in, view enrolled courses, browse course content, submit assignment text, inspect grades, use forums, and view calendar events.
- Lecturers can view assigned courses, manage course sections/items, create forums/calendar events, review rosters, and grade submissions.
- Admins can manage users, create/delete courses, assign lecturers, enroll students, and inspect report dashboards.

## Quick Demo On Windows

Use the root batch files from File Explorer:

1. Double-click `setup.bat`.
2. Edit `backend/.env` and set your local MySQL password.
3. Rebuild the local database if needed:

```powershell
mysql -u root -p < database\schema.sql
mysql -u root -p Vle < database\generated_seed.sql
mysql -u root -p Vle < database\report_views.sql
```

4. Double-click `start_dev.bat`.
5. Open `http://127.0.0.1:5173` if the browser did not open automatically.

You can also start each side separately:

- `start_backend.bat`
- `start_frontend.bat`
- `test.bat`

The batch files call `npm.cmd` directly to avoid common Windows PowerShell execution-policy issues.

## Database and SQL Work

The MySQL database models users, courses, enrollments, lecturers, course sections, assignments, forums, calendar events, and reports.

Key database work includes:

- SQL views for report endpoints.
- Indexes chosen from real route and report queries.
- `EXPLAIN` checks to verify whether MySQL used the intended indexes.
- Seeded demo data so the app can be rebuilt and reviewed locally.
- A `CourseMember` view over `Enrol` and `Teaches`, so course membership is derived instead of duplicated.

The index set is tied to the app's real query patterns. Examples:

| Query Pattern | Index Used | Why It Matters |
| --- | --- | --- |
| Course roster and enrollment reports by course | `idx_enrol_coursecode` | Primary key starts with `userID`, so course-first lookup needs its own index |
| Forum thread list | `idx_discussionthread_forum_threads` | Filters by forum/top-level post and supports newest-first ordering |
| Assignment submissions | `idx_submission_item_date` | Finds submissions for one assignment and supports newest-first ordering |
| Calendar events | `idx_calendarevents_calendar_date_event` | Finds events by course calendar and orders by date/event id |

See `docs/INDEX_EVIDENCE.md` for representative `EXPLAIN` evidence and rejected redundant indexes.

## Manual Commands

The root `.bat` files are the main Windows demo interface. PowerShell helpers remain available under `scripts/` for manual use:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\start_backend.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\start_frontend.ps1
```

Equivalent direct backend command:

```powershell
.\.venv\Scripts\python.exe -m flask --app backend.app run --host 127.0.0.1 --port 5000 --no-reload
```

Equivalent direct frontend command:

```powershell
cd frontend
npm.cmd run dev -- --host 127.0.0.1 --port 5173
```

## Verification

Run the combined local check:

```powershell
cmd /c "set VLE_NO_PAUSE=1&& call test.bat"
```

This runs backend unit tests, Python compile checks, frontend build, frontend lint, and the calendar color test.

Frontend lint currently completes with no reported warnings.
